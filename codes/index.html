How to redeem

  1. Download and open POCKET MYTH, then finish the tutorial.
  2. Open your trainer profile and go to Settings.
  3. Find the redeem code field and paste the code.
  4. Confirm, then check your in-game mail for the rewards.

Each code can normally be used once per character. If a code fails, check the spelling, whether your server is included, and whether the event window is still open.

Gift code questions

Do these codes work on every server?

Most do. A few are tied to a specific server or region, and the note under each code says so when that is the case.

Why does a code say it is invalid?

Usually the event window has closed, the code was already used on that character, or the code is limited to a server you are not on.

How often is this page updated?

Whenever a new code is confirmed. The date at the top of the page shows when it was last checked.
